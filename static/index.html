Kaggle Dataset Acquisition Guide

To train or expand the 2,400 UAV image dataset (1,200 Fire, 1,200 No-Fire), use any of the methods below:

Method 1: Run Pre-configured Python Script
python download_kaggle_dataset.py
Method 2: Using Kaggle CLI
kaggle datasets download -d deepseas/flame-dataset -p ./dataset --unzip
Method 3: Direct Download from Kaggle Web
  1. Visit Kaggle FLAME Dataset or Kaggle Fire Dataset.
  2. Click Download and extract 1200 fire images into static/dataset/fire/.
  3. Extract 1200 no-fire images into static/dataset/no_fire/.
  4. The dashboard automatically standardizes them to 224×224 with CLAHE.
